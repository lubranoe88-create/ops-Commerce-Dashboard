# AVVIO PC — start Plancia locale

**Do not run the `.bat` from inside the zip.** Extract the whole repo first.

1. Download / clone `ops-Commerce-Dashboard` (branch `main`)
2. Right-click zip → **Extract All** → e.g. `Documents\ops-Commerce-Dashboard`
3. Open `DEPLOY_PIANCIA\AVVIO_PC`
4. Double-click `start-plancia-locale.bat`
5. Wait for **Dashboard listening**
6. Open http://127.0.0.1:8787

If the window said the `.ps1` file does not exist, you were still inside Temp/zip — extract all, then retry from the extracted folder.
